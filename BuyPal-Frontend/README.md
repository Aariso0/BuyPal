# BuyPal Frontend

Modern, AI-integrated digital wallet, shared family circles, and smart shopping frontend prototype built with React 18, Vite, and Tailwind CSS.

For a full breakdown of the folder architecture and screen navigation, see **[FOLDER_STRUCTURE_AND_ACCESS_DOC.md](./FOLDER_STRUCTURE_AND_ACCESS_DOC.md)**.

## Quick Start

```bash
cd frontend
npm install
npm run dev
```

Visit `http://localhost:5173` to interact with the application.
Use the **Prototype Screen Navigator** in the bottom-right corner to test all 16 views.
