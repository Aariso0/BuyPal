# BuyPal AI service

Python / FastAPI shopping assistant (intent parsing, product discovery, comparisons, review summaries).
It runs as its own process and is **only called by the BuyPal Node backend** (`backend/src/routes/ai.routes.js`),
which adds login checks, per-user chat sessions, rate limits and input validation. The browser never talks to it directly.

```
Browser (React)  ->  Node backend  /api/v1/ai/*   ->  this service  /api/ai/*
   (session cookie)     (requireAuth + validation)      (127.0.0.1:8000)
```

## Run it

```bash
cd ai
python -m venv venv
source venv/bin/activate            # Windows: venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env                # Windows: copy .env.example .env  — then fill in keys
python main.py                      # listens on http://127.0.0.1:8000
```

Then start the backend (`cd backend && npm run dev`) with `AI_SERVICE_URL` and `AI_SERVICE_TOKEN` set in `backend/.env`
(see `backend/.env.example`). Check it is up: `http://127.0.0.1:8000/health`.

## Configuration (`ai/.env`)

| Variable | Purpose |
|---|---|
| `GROQ_API_KEY` / `GEMINI_API_KEY` / `OPENROUTER_API_KEY` | LLM providers. At least one is required for chat. |
| `CHANNEL3_API_KEY` | Live product catalogue. Without it the agent falls back to web crawling, then to AI-generated suggestions. |
| `AI_SERVICE_TOKEN` | Shared secret; must match `AI_SERVICE_TOKEN` in `backend/.env`. |
| `AI_AGENT_HOST` / `AI_AGENT_PORT` | Bind address (default `127.0.0.1:8000`). |
| `AI_CORS_ORIGINS` | Leave empty. Only for calling the service from a browser during development. |

## Changes made to the original agent when integrated into BuyPal

Only `main.py` and `requirements.txt` differ from the original `ai_agent` folder:

- `main.py`: default host `0.0.0.0` -> `127.0.0.1`; CORS `*` -> closed unless `AI_CORS_ORIGINS` is set;
  optional `x-ai-service-token` check on `/api/ai/*` (except `/api/ai/health`).
- `requirements.txt`: added `httpx` (imported directly by the code; it was only present transitively via `groq`).

`agent.py`, `channel3_client.py`, `memory.py`, `models_provider.py`, `schemas.py`, `web_search_client.py` are unchanged.

## Things to know

- Session memory is in-process (`memory.py`). Restarting the service clears all conversations.
- Product data comes from, in order: Channel3 catalogue, live web crawl (Flipkart/Amazon India/Myntra),
  then **LLM-generated suggestions** (`execution_mode: "ai_intelligence"`). The last tier is not live data; the BuyPal UI labels it.
- The prices are in the retailer's currency (mostly INR). BuyPal wallet balances are USD demo balances; nothing is converted.
- `trusted_review` output is generated by the LLM and is not fetched from the sites it names. The UI labels it accordingly.
